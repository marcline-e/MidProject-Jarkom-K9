Portal Smart City Surabaya

Kelompok 9 | Jaringan laboratorium k9.smartcity.lab

Portal internal untuk uji komunikasi Balai Kota, Pelabuhan, dan wilayah Smart City.

Layanan jaringan

Portal Balai Kota
www.k9.smartcity.lab, server web di LAN Server Balai Kota.
Penyimpanan CCTV
ftp.k9.smartcity.lab, unggah berkas dengan akun FTP melalui Command Prompt.
Email pegawai
mail.k9.smartcity.lab, kirim dan terima pesan melalui aplikasi Email Packet Tracer.

Petunjuk uji

Buka portal ini dari host setiap wilayah menggunakan nama domain, bukan alamat IP.

Untuk uji CCTV, unggah rekaman-cctv-k9.txt dari perangkat CCTV KOTA ke server FTP DC. Berkas tersebut adalah data uji, bukan rekaman kamera asli.

Untuk uji email, gunakan akun user-pusat dan user-pelabuhan pada domain k9.smartcity.lab.

Simulasi Cisco Packet Tracer untuk Mid Project Jarkom. Bukan layanan resmi Pemerintah Kota Surabaya.
